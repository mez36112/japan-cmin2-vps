## 搬瓦工的“日本 CMIN2”到底是怎么回事

它家目前有三个日本相关机房：大阪软银 JPOS_1、大阪 CN2 GIA（JPOS_6）和东京 CN2 GIA。其中只有 JPOS_1 面向普通 CN2 GIA-E 用户开放，走的是软银 bbtec 网络（AS17676），位于大阪。软银线路的特点很明确：**对联通用户极佳，电信用户晚高峰限速明显**（有第三方测评测到过 500KB/s 左右的水平），移动回程则走日本软银对接移动骨干。

## 流量怎么算：一个写在小字里的规则

搬瓦工的月流量是**双向计费**的，上传和下载都算进去，按月重置。流量用超不会自动扣费，而是直接停机，等下一个计费周期才恢复。建议在 KiwiVM 后台把流量预警设在 80%，留出余量。

这个规则和竞品的处理方式差别很大：GoMami 超流量后是限速到 20KB/s 直到下个周期，不扣超量费；搬瓦工是直接停机。两者都 nocost 超量费，但停机对跑业务的用户更致命，买套餐时流量档位宁高勿低。
